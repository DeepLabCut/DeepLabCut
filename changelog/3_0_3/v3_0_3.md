# DeepLabCut 3.0.3

DeepLabCut 3.0.3 is a patch release with better handling of undetected poses along inference and security-related dependency bumps, as well as adding more flexibility to PyTorch data loading.

## Highlights

- New `dataloader_kwargs` in `train_settings` to configure the PyTorch `DataLoader` (#3550, #3576).
- Top-down inference no longer skips frames without detections; warn about unreadable videos (#3488).
- Fix wrong multi-animal tracking when an ellipse fit fails on one animal (#3544).
- Fix wrong starting frame in k-means frame extraction for consecutive indices (#3531).
- Fix GUI freeze when showing trajectory plots in Analyze Videos (#3466).

## Important changes

### Train settings: `dataloader_kwargs` (#3550, #3576)

`TrainSettingsConfig` now has a `dataloader_kwargs` field for forwarding additional parameters to the PyTorch DataLoader (e.g. `persistent_workers`, `prefetch_factor`).
Please see [related documentation](https://github.com/DeepLabCut/DeepLabCut/blob/main/docs/pytorch/pytorch_config.md#train-settings).

> [!NOTE]
> `pytorch_config.yaml` only contains `dataloader_kwargs` when set manually. Configurations that leave it unset can still be used in <=3.0.2; configurations that did set it cannot, unless the field is removed.
